## PART 1: QUESTION PAPER STRUCTURE

### Overview
- **Total Questions:** 9 (all compulsory)
- **Total Pages:** 3
- **Total Marks:** 20
- **Sections:** A, B, C, D, E
- **No Overall Choice:** Students must answer all questions

### Section Breakdown

#### **SECTION A: Multiple Choice Questions (MCQ)**
| Attribute | Details |
|-----------|---------|
| Questions | 1 to 4 (4 questions) |
| Type | Objective Type (OT) |
| Marks per Q | 1 mark |
| Total Marks | 4 marks (20%) |
| Format | 4 options each (a, b, c, d) |
| Q4 Special Format | Assertion-Reason |
| Answer Length | Single selection |

**Example Q4 Format (Assertion-Reason):**
- Both A and R true, R is correct explanation
- Both A and R true, R is NOT correct explanation
- A true but R false
- A false but R true

#### **SECTION B: Very Short Answer (VSA)**
| Attribute | Details |
|-----------|---------|
| Questions | 5 to 6 (2 questions) |
| Type | Short Answer I (SA I) |
| Marks per Q | 2 marks |
| Total Marks | 4 marks (20%) |
| Answer Length | 30-50 words |
| Format | Usually 2 sub-parts |
| Content Type | Justification, comparison, identification |

#### **SECTION C: Short Answer (SA)**
| Attribute | Details |
|-----------|---------|
| Questions | 7 (1 question) |
| Type | Short Answer II (SA II) |
| Marks | 3 marks (15%) |
| Answer Length | 50-80 words |
| Format | 2-3 sub-parts with diagram/image |
| Content Type | Labeling, identification, function |

#### **SECTION D: Long Answer (LA)**
| Attribute | Details |
|-----------|---------|
| Questions | 8 (1 question) |
| Type | Long Answer (LA) |
| Marks | 5 marks (25%) |
| Answer Length | 80-120 words |
| Format | 3 sub-parts |
| Content Type | Process description, comprehensive explanation |

#### **SECTION E: Case-Based Assessment (CBQ)**
| Attribute | Details |
|-----------|---------|
| Questions | 9 (1 question) |
| Type | Source/Case-Based Question (CBQ) |
| Marks | 4 marks (20%) |
| Format | Table with hints + 2-3 sub-questions |
| Content Type | Scenario analysis, identification |
| Sub-parts | 2-3 questions based on case |

**Example:** Table showing hints like:
- (i) "A hard bone-like structure called X"
- (ii) "Covered with hard covering Y (hardest substance)"
- (iii) "Sticky yellowish layer Z forms due to poor hygiene"
- (iv) "Z produces acids that corrode Y"

Students identify X, Y, Z and explain properties.

### Learning Domain Definitions

- **R/U (40%):** Recall of facts, basic comprehension, direct application of definitions
  - Question Types: MCQ, VSA with direct definitions, SA with simple identification

- **Ap (40%):** Apply concepts to new situations, solve problems, interpret data
  - Question Types: MCQ with scenarios, SA with experiments, LA with process explanation

- **An/E (20%):** Analyze relationships, evaluate evidence, make judgments
  - Question Types: Assertion-Reason MCQ (2 questions), analytical SA

## PART 3: QUESTION PAPER VARIATIONS (A, B, C, D)

### Consistency Across All 4 Papers
✓ **IDENTICAL STRUCTURE:** All 4 papers follow the same 5-section format
✓ **IDENTICAL MARKS:** All papers total 20 marks
✓ **IDENTICAL QUESTION TYPES:** Same distribution of MCQ, VSA, SA, LA, CBA
✓ **IDENTICAL BLUEPRINT:** Same learning domain distribution

### Content Variations
- **Different question sets:** Each paper tests different concepts within same chapters
- **Different organisms/examples:** Sundew plant vs Venus flytrap, Lichens vs other examples
- **Different experiments:** Different lab scenarios, different organisms studied
- **Different case scenarios:** Different quiz hints, different body parts, different processes

### Benefits of 4-Paper System
1. **Reduced cheating:** Students can't share answers across parallel exams
2. **Fair assessment:** All students tested on same competencies
3. **Fairness verification:** Easy to verify question difficulty is similar
4. **Alternative versions:** Can administer to different batches/slots

### Assessment Flow for Students

1. **Entry:** See instructions, timer starts
2. **Section A:** Complete MCQs, get immediate feedback
3. **Sections B-E:** Complete with word count guidance, save drafts
4. **Review:** See all responses before submission
5. **Submit:** Final submission triggers auto-scoring + manual grading queue

### Grading Workflow for Teachers

1. **Stage 1:** Auto-score Section A (instant)
2. **Stage 2:** Queue B-E for manual grading
3. **Stage 3:** Teachers grade using rubric templates
4. **Stage 4:** System calculates final marks and generates result

## PART 6: CONTENT TOPICS COVERED

### Chapter 1: Nutrition in Plants
- Plant adaptations (pitcher plant, sundew, venus flytrap)
- Parasitic plants (Cuscuta, haustoria)
- Symbiotic relationships (lichens, mycorrhizae)
- Photosynthesis process
- Saprophytic plants

### Chapter 2: Nutrition in Animals
- Types of teeth and their functions
- Digestive system (mouth, esophagus, stomach, small intestine, large intestine)
- Enzymes in digestion (pepsin, amylase)
- Gastric juices and their components
- Ruminant digestion (cow's 4-chambered stomach)
- Detritivores and decomposers
- Parasites (ectoparasites, endoparasites)
- Ingestion methods in different organisms
- Salivary digestion
