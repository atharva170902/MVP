DIFFERENT SCENARIOS:

Scenario 1: NOT ENOUGH MARKS (15 / 20)
┌──────────────────────────────────────────┐
│ Total Marks Allocated: 15 / 20           │  ⚠️ YELLOW
│ ⚠️ 5 marks remaining.                    │
│ Please allocate all marks.               │
└──────────────────────────────────────────┘
Button: DISABLED (gray)

Scenario 2: TOO MANY MARKS (22 / 20)
┌──────────────────────────────────────────┐
│ Total Marks Allocated: 22 / 20           │  ❌ RED
│ ❌ 2 marks over the limit.               │
│ Please reduce.                           │
└──────────────────────────────────────────┘
Button: DISABLED (gray)

┌──────────────────────────────────────────┐

│ ✅ All marks allocated correctly!        │

MARKS INPUT:

User can enter:
- Any number from 0 to total marks (e.g., 0-20)
- Input shows in a box with chapter name on left

Example:
┌─────────────────────────────────────┐
│ Nutrition in Plants  [5] marks      │
└─────────────────────────────────────┘
(Click the [5] to edit)

================================================================================

BUTTON STATES:

DISABLED (while marks < or > total):
┌────────────────────────────┐
│ Continue to Step 3 ❌       │
│ (Gray background)          │
│ Hover: "Please allocate    │
│ exactly 20 marks"          │
└────────────────────────────┘

ENABLED (when marks = total):
┌────────────────────────────┐
│ Continue to Step 3 ✅       │
│ (Blue background, clickable)
└────────────────────────────┘

================================================================================

SUMMARY:

1. User selects chapters (click checkbox)
2. System shows marks input fields
3. User enters marks for each chapter
4. System calculates total in real-time
5. Shows color status (red/yellow/green)
6. Shows helpful message
7. Button enables only when total = exam total marks
8. User clicks Continue to Step 3
