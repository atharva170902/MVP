DYNAMODB TABLE STRUCTURE
========================

Table: "sessions"
- Partition Key: userId (String)
- Sort Key: draftId (String)
- Global Secondary Index: userId-updatedAt-gsi
- Billing: PAY_PER_REQUEST (no SQL, auto-scaling)

ADVANTAGES OVER SQL
===================

✅ No SQL schema needed
✅ Auto-scaling (pay per request)
✅ Built-in multi-tenancy
✅ Global secondary indexes
✅ 99.99% uptime SLA
✅ Faster to setup (~1-2 hours vs ~4-7 hours)
